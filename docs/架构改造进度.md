### B. 任务、来源与可靠性

- [ ] **B-01｜下一批：持久确认预览来源绑定与在途终态。** 核对 `DatabasePendingMutationStore` 的 prepare/claim/complete/mark_unknown；删源和撤销后不能继续受理或回写来源内容，已发外部操作如实保留结果未知/回执；覆盖重启与并发。
- [ ] **B-02｜待核对：全域删除血缘清单。** 逐域登记来源和派生关系、独立已接受产物、删除入口、来源围栏与恢复重放路径；给每项对应的实现/测试链接。

- [ ] **B-04｜待核对与补齐：剩余入口任务关联。** 逐入口确认 owner/session/device、Run/父 Run、取消、deadline 与 postcommit 来源，避免独立任务被误取消或来源任务脱离血缘。
