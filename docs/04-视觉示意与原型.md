## 1. 产品界面概念图

![Aria 桌面端高保真概念图](./visuals/aria-desktop-concept-v1.png)

这张图用于表达产品气质和信息层级，不是最终 UI 定稿。核心结构为：

- 左侧：会话、连接状态、模型/记忆/设备健康度；
- 中间：伴侣形象、主对话、快捷动作；
- 右侧：当前状态、相关记忆、隐私路由和主动互动；
- 关键原则：用户能看见“为什么这样回应、用了什么记忆、数据去了哪里”。

## 3. 一次对话如何可靠完成

```mermaid
sequenceDiagram
    actor U as 用户
    participant G as 输入网关
    participant DB as Event/Outbox
    participant C as 认知消费者
    participant M as 记忆系统
    participant L as LLM Router
    participant O as 输出消费者

    U->>G: 发送消息
    G->>G: 鉴权、校验、服务端隐私定级
    G->>DB: 同一事务写 event + outbox
    DB-->>U: 已接收 event_id
    DB->>C: 至少一次投递
    C->>C: inbox 幂等检查
    C->>M: 检索有效且同隐私域的记忆
    M-->>C: memory_id + 来源 + 分项得分
    C->>L: EgressGuard 检查后的上下文
    L-->>C: 结构化 AgentReply
    C->>DB: 同一事务写回复事件 + inbox
    DB->>O: 投递 OutputIntent / DeliveryPlan
    O->>O: action_id 幂等检查
    O-->>U: 流式文字 / 语音 / 表情

    Note over DB,O: 任一服务崩溃均可重投；业务唯一键防止重复回复与重复记忆
```

## 5. 记忆生命周期

```mermaid
stateDiagram-v2
    [*] --> Candidate: 对话或事件产生候选
    Candidate --> Rejected: 低置信 / 敏感越界 / 无价值
    Candidate --> Active: 新事实或经历
    Candidate --> Supported: 支持已有事实
    Candidate --> Conflict: 与已有事实冲突
    Conflict --> Active: 用户确认或规则裁决
    Active --> Superseded: 被新事实替代
    Active --> Archived: 低重要性且长期未访问
    Active --> Deleting: 用户要求忘记
    Supported --> Active
    Superseded --> Deleting
    Archived --> Deleting
    Deleting --> [*]: 原文/向量/摘要/缓存/衍生记忆清理

    note right of Active
      保存来源、有效期、置信度、
      embedding 与提取器版本
    end note
```
